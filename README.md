# 🛒 MERN Ecommerce Platform

A full-stack Ecommerce web application built using the MERN stack (MongoDB, Express.js, React.js, Node.js).

This project simulates a real-world ecommerce platform with authentication, product management, cart functionality, wishlist system, and secure API integration.

## 🚀 Live Demo

Live Website:
https://mern-ecommerce-blackwinter-ihug.vercel.app/

---

# 📌 Features

- User Authentication (JWT)
- Product Listing
- Product Details Page
- Add to Cart
- Wishlist Feature
- Responsive UI
- REST API Integration
- MongoDB Database
- MERN Stack Architecture
- Deployment using Vercel

# 🔐 Authentication Flow

1. User logs in
2. Frontend sends credentials
3. Backend validates user
4. JWT token generated
5. Protected routes accessed

---

# 🛒 Cart Workflow

1. User clicks Add to Cart
2. Frontend sends API request
3. Backend updates cart data
4. MongoDB stores cart items
5. Updated cart displayed

# ⚙️ Installation

## Install Frontend

```bash
cd frontend
npm install
npm run dev
```

## Install Backend

```bash
cd backend
npm install
npm start
```
